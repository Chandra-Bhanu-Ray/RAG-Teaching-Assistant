# RAG-Teaching-Assistant

An AI-powered teaching assistant that helps students understand their study materials by answering questions using Retrieval-Augmented Generation (RAG).

## Features
- Ask questions based on study materials.
- Retrieve relevant information from documents.
- Generate context-based AI responses.
- Simplify the learning process.
- Interactive question-answering system.

## Technologies Used
- Python
- RAG (Retrieval-Augmented Generation)
- Large Language Models (LLMs)
- Embedding Models
- Vector Database

## How It Works
1. Upload educational documents.
2. Process and split documents into smaller chunks.
3. Convert text into vector embeddings.
4. Retrieve relevant content based on user queries.
5. Generate answers using the retrieved context and an AI model.

## Objective

To make learning easier and more interactive by allowing students to ask questions and receive answers directly from their study materials.
