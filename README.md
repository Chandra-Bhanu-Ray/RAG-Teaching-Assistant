# RAG Teaching Assistant

An AI-based teaching assistant that answers students' questions using information from their study materials through Retrieval-Augmented Generation (RAG).

## Features
- Document-based question answering
- Relevant information retrieval
- AI-generated contextual responses
- Interactive learning experience

## Technologies
- Python
- Retrieval-Augmented Generation (RAG)
- Large Language Models (LLMs)
- Embedding Models
- Vector Database

## Workflow
1. Upload study materials.
2. Extract and split document content into chunks.
3. Generate embeddings and store them.
4. Retrieve relevant information based on user queries.
5. Generate answers using the retrieved context.

## Objective

To make learning easier by helping students find answers directly from their study materials.
